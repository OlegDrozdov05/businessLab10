# NFR-06. Локализация

## Требование
В первоначальной версии приложение должно быть полностью локализованно на русский язык. В последующих версиях должна быть добавлена поддержка английского языка.

## Атрибуты
Источник: бизнес-требования   
Приоритет: средний  
Стабильность: стабильное  

## Связанные требования
Все пользовательские требования должны быть переведены
