# NFR-03. Доступность

## Требование
1. Приложение должно поддерживать режим «крупный шрифт» (не менее 18pt) и контрастный интерфейс для слабовидящих пользователей.
2. Все интерактивные элементы должны быть доступны для управления голосовым ассистентом.
3. Push-уведомления должны корректно доставляться на устройствах с iOS и Android при условии разрешения пользователя.

## Атрибуты
Источник: потребности пожилых людей     
Приоритет: средний 
Стабильность: стабильное
