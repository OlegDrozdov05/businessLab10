# NFR-01. Производительность

## Требование
1. Время отклика интерфейса на действия пользователя (нажатие кнопок, открытие экранов) не должно превышать 1 секунды для 95% операций.
2. Поиск продукта по названию должен возвращать результаты не более чем за 1 секунду при стабильном интернете.
3. Загрузка видеоролика упражнения должна начинаться не позднее чем через 2 секунды после перехода к упражнению.

## Атрибуты
Источник: Общее требование   
Приоритет: высокий  
Стабильность: стабильное
