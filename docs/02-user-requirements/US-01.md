# US-01. Выбор цели

## Требование
Пользователь имеет возможность выбрать свою цель (похудение, поддержание формы, набор мышечной массы) при первом запуске приложения, чтобы получать персонализированные рекомендации.

## Роли
- Начинающий пользователь
- Спортсмен
- Пожилой человек

## Атрибуты
Источник: бизнес-требования 
Приоритет: высокий
Стабильность: стабильное
