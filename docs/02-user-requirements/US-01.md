# US-01. Выбор цели

## Требование

При первом запуске приложения пользователь **обязан** выбрать свою цель из трёх вариантов (похудение, поддержание формы, набор мышечной массы).
Пропустить этот шаг нельзя, однако при отсутствии выбора в течение 30 секунд автоматически устанавливается цель "поддержание формы".
После завершения онбординга пользователь может изменить цель в любое время в разделе "Настройки" -> "Мои цели".
Выбранная цель используется для генерации персонализированных рекомендаций по питанию и тренировкам.
Роли не влияют на доступные цели, но влияют на сложность и формат рекомендаций.

## Роли

- Начинающий пользователь
- Спортсмен
- Пожилой человек

## Атрибуты
