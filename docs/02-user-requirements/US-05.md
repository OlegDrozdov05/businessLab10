# US-05. Ручной ввод шагов

## Требование
Пользователь может вручную указать количество шагов, пройденных за день (с помощью кнопок +/-).

## Роли
- Пожилой человек
- Начинающий пользователь

## Атрибуты
Источник: Анализ возрастной аудитории  
Приоритет: высокий  
Стабильность: стабильное
