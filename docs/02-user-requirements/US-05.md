# US-05. Ручной ввод шагов

## Требование

Пользователь может вручную указать количество шагов, пройденных за день.
Интерфейс предоставляет:

- поле для прямого ввода числа с клавиатуры (диапазон от 0 до 50 000),
- кнопки "+" и "-" с шагом изменения 100 шагов.

Введённое значение сохраняется и отображается в дневнике активности.

## Роли

- Пожилой человек
- Начинающий пользователь

## Атрибуты

Источник: Анализ возрастной аудитории  
Приоритет: высокий  
Стабильность: стабильное
