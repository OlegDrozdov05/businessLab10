# US-05. Ручной ввод шагов

## Требование
Пользователь может вручную указать количество шагов, пройденных за день (с помощью кнопок +/-), если у него нет фитнес-трекера или он не хочет его подключать.

## Роли
- Пожилой человек
- Начинающий пользователь

## Атрибуты
Источник: Анализ возрастной аудитории  
Приоритет: высокий  
Стабильность: стабильное
