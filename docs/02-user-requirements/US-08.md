# US-08. Интеграция с фитнес-трекерами

## Требование
Спортсмен может подключить свои смарт-часы или фитнес-браслет (Garmin, Polar, Apple Watch, Xiaomi) для автоматической синхронизации пульса, шагов, калорий и сна.

## Роли
- Спортсмен
  
## Атрибуты
Источник: потребности пользователей  
Приоритет: низкий  
Стабильность: зависит от API производителей
