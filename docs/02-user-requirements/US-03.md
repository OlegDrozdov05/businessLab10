#US-03. План тренировок

## Требование
Пользователь получает готовый недельный план тренировок (4-5 занятий по 15-30 мин) с короткими видео каждого упражнения и может отмечать выполненные тренировки.

## Роли
- Начинающий пользователь
- Спортсмен
- Пожилой человек (имеет доступ только к простым тренировкам)

## Атрибуты
Источник: бизнес-требования 
Приоритет: высокий
Стабильность: стабильное
