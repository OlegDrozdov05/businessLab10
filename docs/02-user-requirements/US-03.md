# US-03. План тренировок

## Требование

1. **Получение плана тренировок.** Пользователь получает готовый недельный план тренировок (4–5 занятий по 15–30 мин) с короткими видео каждого упражнения. План генерируется на основе выбранной цели и роли пользователя. Для роли "Пожилой человек" план включает только "простые тренировки": без прыжков, без упражнений на равновесие, без быстрой смены положения, с длительным отдыхом между подходами не менее 30 секунд.

2. **Отметка выполнения.** Пользователь может отметить каждую тренировку как выполненную. Отметка сохраняется в дневнике активности и влияет на прогресс и рекомендации.

## Роли

- Начинающий пользователь
- Спортсмен
- Пожилой человек (имеет доступ только к простым тренировкам)

## Атрибуты

Источник: бизнес-требования  
Приоритет: высокий  
Стабильность: стабильное
