# US-02. Ручной ввод еды

## Требование
Пользователь может искать продукты в базе, указывать порцию (в граммах, штуках, стаканах) и добавлять их в дневник питания, чтобы видеть суммарное КБЖУ за день.

## Роли
- Начинающий пользователь
- Спортсмен
- Пожилой человек

## Атрибуты
Источник: бизнес-требования 
Приоритет: высокий
Стабильность: стабильное
