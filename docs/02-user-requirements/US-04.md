# US-04. Напоминания о воде

## Требование
Пользователь может включить регулярные push-уведомления с напоминанием выпить стакан воды и отмечать количество выпитой воды за день.

## Роли
- Начинающий пользователь
- Пожилой человек

## Атрибуты
Источник: данные о здоровье  
Приоритет: высокий  
Стабильность: стабильное
