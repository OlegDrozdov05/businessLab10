# US-07. Получение рекомендаций

## Требование

Пользователь получает персональные рекомендации по питанию и физической активности.

**Формат:** текстовые карточки внутри приложения раздел "Рекомендации»" и опционально push-уведомления, настраиваемые пользователем.

**Периодичность:**

- ежедневно в 9:00 - общие рекомендации на день;
- при изменении цели, веса или завершении тренировки - моментальное обновление.

**Критерии персонализации:**

- выбранная цель: похудение, поддержание, набор массы;
- данные о прогрессе: выполненные тренировки, дефицит/профицит калорий, количество шагов;
- ограничения по здоровью (если указаны в профиле).

Рекомендация считается релевантной, если она учитывает хотя бы два из трёх критериев.

## Роли

- Начинающий пользователь
- Спортсмен

## Атрибуты

Источник: бизнес-возможности  
Приоритет: высокий  
Стабильность: стабильное
