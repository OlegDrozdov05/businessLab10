# US-07. Получение рекомендаций

## Требование
Пользователь получает персональные рекомендации по питанию и физической активности на основе своей цели, введённых данных и прогресса.

## Роли
- Начинающий пользователь
- Спортсмен
  
## Атрибуты
Источник: бизнес-возможности  
Приоритет: высокий  
Стабильность: стабильное
