# US-06. Просмотр прогресса

## Требование

### Базовый прогресс (доступен всем пользователям)

Пользователь может видеть количество выполненных тренировок за текущую неделю в виде простого счётчика или столбчатой диаграммы.

### Расширенный прогресс (доступен для спортсменов)

Пользователь может просматривать:

- графики изменения веса, пульса, мышечной массы (если вносится вручную);
- доступные периоды: день, неделя, месяц, квартал;
- наложение двух периодов для сравнения, например, текущая неделя и предыдущая;
- отображение рекордов таких, как максимальное количество шагов за день, максимальная продолжительность тренировки и т.п.

Тип графиков - линейный для веса, пульса, массы и столбчатый для тренировок.

## Роли

- Начинающий пользователь
- Спортсмен

## Атрибуты

Источник: потребности спортсменов  
Приоритет: средняя  
Стабильность: средняя
