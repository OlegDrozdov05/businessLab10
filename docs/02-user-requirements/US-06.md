# US-06. Просмотр прогресса

## Требование
Пользователь может видеть свой прогресс: количество выполненных тренировок за неделю, а в расширенной версии – графики изменения веса, пульса, мышечной массы за разные периоды.

## Роли
- Начинающий пользователь
- Спортсмен 

## Атрибуты
Источник: потребности спортсменов  
Приоритет: средняя  
Стабильность: средняя
