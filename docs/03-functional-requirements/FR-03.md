# FR-03. Генерация плана тренировок

## Требование
Система должна генерировать недельный план тренировок на основе выбранной пользователем цели. План должен включать 4-5 тренировок разной длительности (15-30 мин), каждая тренировка состоит из упражнений с видео-инструкцией. 
Пользователь может отметить тренировку как выполненную.

## Атрибуты
Источник: US-03  
Приоритет: высокий  
Стабильность: стабильное
