# FR-03. Генерация плана тренировок

## FR-03.1 Генерация плана
Система должна генерировать недельный план тренировок на основе выбранной пользователем цели. 
План должен включать 4–5 тренировок разной длительности (конкретные значения: 15, 20, 25, 30 минут - выбираются случайным образом). 
Каждая тренировка состоит из упражнений с видео-инструкцией.

## FR-03.2 Отметка выполнения
Система должна предоставлять пользователю возможность отметить тренировку как выполненную. 
Отметка сохраняется в дневнике активности и учитывается при расчёте прогресса.
