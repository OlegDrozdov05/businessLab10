# FR-08. Кэширование для работы офлайн

## Требование
Система должна кэшировать локально (на устройстве) не менее 200 последних использованных продуктов и все записи дневника пользователя за последние 30 дней, 
чтобы обеспечить базовую функциональность (добавление продуктов, отметка тренировок) при отсутствии интернета. При восстановлении соединения данные синхронизируются с сервером.

## Атрибуты
Источник: решение разработчиков  
Приоритет: средний  
Стабильность: стабильное
