# FR-01. База продуктов

## Требование
Система должна предоставлять базу данных продуктов питания (не менее 5000 записей в первоначальной версии) с возможностью поиска по названию (автодополнение) и получения информации о КБЖУ на 100 г продукта.

## Атрибуты
Источник: US-02  
Приоритет: высокий  
Стабильность: стабильное
