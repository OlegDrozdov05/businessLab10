# FR-09. Синхронизация с фитнес-трекерами

## Требование
Система должна поддерживать OAuth-авторизацию для подключения фитнес-трекеров (Garmin, Polar, Apple Watch, Xiaomi) 
и выполнять синхронизацию данных (шаги, пульс, сожжённые калории) не реже 1 раза в час в фоновом режиме (при наличии интернета и разрешения пользователя).
Данные сохраняются в БД и используются для графиков и рекомендаций.

## Атрибуты
Источник: US-08  
Приоритет: низкий  
Стабильность: зависит от API фитнесс-трекеров
