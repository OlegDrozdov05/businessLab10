# FR-06. Онбординг и выбор цели

## Требование
При первом запуске системы пользователь должен пройти онбординг: выбрать цель из трёх вариантов (похудение, поддержание формы, набор массы), 
ввести базовые параметры (вес, рост, возраст, уровень активности – опционально). 
Выбранная цель сохраняется в профиле и используется для всех последующих рекомендаций. Пользователь может изменить цель в настройках.

## Атрибуты
Источник: US-01  
Приоритет: высокий  
Стабильность: стабильное
