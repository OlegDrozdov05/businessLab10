# FR-10. Экспорт данных

## Требование
Система должна предоставлять возможность экспорта истории тренировок, веса и питания в формате CSV (Excel). Пользователь может выбрать диапазон дат.

## Атрибуты
Источник: US-06  
Приоритет: низкий  
Стабильность: стабильное
