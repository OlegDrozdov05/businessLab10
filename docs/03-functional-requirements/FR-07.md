# FR-07. Ручной ввод шагов

## Требование
Система должна предоставлять пользователю интерфейс для ручного ввода количества шагов за текущий день: поле ввода с кнопками +/- (шаг изменения – 100 шагов, допускается ввод от 0 до 50 000). Значение сохраняется и отображается в дневнике активности.

## Атрибуты
Источник: US-05  
Приоритет: высокий  
Стабильность: стабильное
