# FR-02. Расчёт КБЖУ для порции

## Требование
Система должна рассчитывать калории, белки, жиры, углеводы для указанной пользователем порции продукта (умножение справочных данных на коэффициент порции/100). Для единиц «штука» используется предустановленный вес одной штуки.

## Атрибуты
Источник: US-02  
Приоритет: высокий  
Стабильность: стабильное
