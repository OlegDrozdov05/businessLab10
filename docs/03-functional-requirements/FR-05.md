# FR-05. Графики прогресса

## Требование
Система должна отображать графики изменения веса, пульса (при наличии данных), 
выполненных тренировок за выбранные периоды (день, неделя, месяц, квартал). Также доступно наложение двух периодов для сравнения и отображение рекордов.

## Атрибуты
Источник: US-06  
Приоритет: средний  
Стабильность: стабильное
