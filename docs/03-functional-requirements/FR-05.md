# FR-05. Графики прогресса

## FR-05.1 Отображение графиков
Система должна отображать линейные графики изменения веса и пульса (при наличии данных) за выбранные периоды: день, неделя, месяц, квартал. 
Для выполненных тренировок - столбчатая диаграмма в виде количества тренировок за период.

## FR-05.2 Наложение двух периодов
Система должна позволять накладывать два периода на одном графике для визуального сравнения.

## FR-05.3 Отображение рекордов
Система должна отображать лучшие достижения пользователя: максимальное количество шагов за день, максимальную продолжительность тренировки, максимальный вес в упражнении и т.п.
