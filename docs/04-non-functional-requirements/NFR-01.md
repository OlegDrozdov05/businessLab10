# NFR-01. Производительность

## NFR-01.1 Отклик интерфейса
Время отклика интерфейса на действия пользователя  не должно превышать 1 секунды для 95% операций, измеренных в условиях стабильного интернета (скорость не менее 1 Мбит/с, задержка не более 200 мс).

## NFR-01.2 Поиск продукта
Поиск продукта по названию должен возвращать результаты не более чем за 1 секунду при стабильном интернете.

## NFR-01.3 Загрузка видео
Загрузка видеоролика упражнения должна начинаться не позднее чем через 2 секунды после перехода к упражнению при стабильном интернете.


## Атрибуты
Источник: Общее требование   
Приоритет: высокий  
Стабильность: стабильное
