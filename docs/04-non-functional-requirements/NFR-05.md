# NFR-05. Надёжность

## NFR-05.1 Обработка ошибок сети
Приложение должно корректно обрабатывать ошибки сети:
- при отсутствии соединения - отображать понятное сообщение и переходить в офлайн-режим (функции, не требующие сети, доступны);
- при временной потере соединения во время запроса - автоматически повторять запрос до 3 раз с экспоненциальной задержкой (1с, 2с, 4с);
- после восстановления сети - синхронизировать локальные изменения с сервером без потери данных.

## NFR-05.2 Автосохранение дневника
Записи дневника пользователя (еда, вода, шаги, тренировки) не должны теряться при сбоях. Система должна выполнять автосохранение каждые 30 секунд в локальное хранилище.

## NFR-05.3 Доступность API
Доступность API должна быть не менее 99.5% времени в месяц, измеряемая с помощью внешнего мониторинга каждые 5 минут.
