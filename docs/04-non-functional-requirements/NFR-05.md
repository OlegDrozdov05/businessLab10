# NFR-05. Надёжность

## Требование
1. Приложение должно корректно обрабатывать ошибки сети.
2. Записи дневника пользователя не должны теряться при сбоях (автосохранение каждые 30 секунд).
3. Доступность серверной части (API) должна быть не менее 99.5% времени в месяц.

## Атрибуты
Источник: Общее требование   
Приоритет: высокий  
Стабильность: стабильное
