# NFR-02. Безопасность

## Требование
1. Все сетевые запросы должны выполняться по протоколу HTTPS.
2. Токены доступа к API фитнес-трекеров должны храниться в зашифрованном виде (AES-256).
3. Пароли пользователей (если реализована аутентификация) должны хэшироваться с солью (bcrypt).
4. Приложение не должно запрашивать лишние разрешения (только необходимые для работы).

## Атрибуты
Источник: стандарты безопасности   
Приоритет: высокий  
Стабильность: стабильное
