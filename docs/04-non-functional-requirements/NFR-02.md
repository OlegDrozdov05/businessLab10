# NFR-02. Безопасность

## NFR-02.1 Шифрование каналов

Все сетевые запросы должны выполняться по протоколу HTTPS.

## NFR-02.2 Хранение токенов

Токены доступа к API фитнес-трекеров должны храниться в зашифрованном виде (AES-256).

## NFR-02.3 Хэширование паролей

Пароли пользователей должны хэшироваться с солью (bcrypt, стоимость 10).

## NFR-02.4 Разрешения приложения

Приложение не должно запрашивать разрешения, не указанные в следующем списке допустимых:

- доступ к уведомлениям для напоминаний,
- доступ к камере для сканирования штрих-кодов продуктов,
- доступ к файловой системе для экспорта CSV, только чтение/запись в собственную директорию.

Запрещены: доступ к контактам, SMS, календарю, геолокации без явного согласия пользователя для специфической функции.

## Атрибуты

Источник: стандарты безопасности  
Приоритет: высокий  
Стабильность: стабильное
