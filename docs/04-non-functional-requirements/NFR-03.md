# NFR-03. Доступность

## NFR-03.1 Крупный шрифт и контрастность
Приложение должно поддерживать режим "крупный шрифт": размер не менее 18pt. 
Коэффициент контрастности текста и фона для основных элементов интерфейса должен быть не менее 4.5:1 по стандарту WCAG AA.

## NFR-03.2 Голосовое управление
Все интерактивные элементы (кнопки, поля ввода, переключатели) должны быть доступны для управления с помощью голосового ассистента (VoiceOver на iOS, TalkBack на Android) - все элементы должны иметь осмысленные метки и правильно обрабатывать фокус.

## NFR-03.3 Push-уведомления
Push-уведомления должны корректно доставляться на устройствах с iOS и Android при условии, что пользователь дал разрешение. 
"Корректная доставка" означает, что уведомление достигает устройства в течение 30 секунд после отправки сервером при стабильном интернете и отображается в системном трее. 
Проверяется с помощью тестового пула из 100 устройств: успех ≥99%.
